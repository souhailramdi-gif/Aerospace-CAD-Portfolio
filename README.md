# Aerospace CAD Portfolio

A collection of aerospace and engineering CAD projects developed using Siemens NX as part of my Aerospace Engineering studies.

## Projects

### Aircraft Wing & Airfoil
Created an aircraft wing model using real airfoil coordinate data. The model was developed in Siemens NX using spline, datum plane, scale curve, through curve and project curve features.

The project also supported my study of aerodynamic behaviour, including how air velocity and pressure vary around an airfoil.

### Jet Engine
Developed a 3D jet engine model in Siemens NX from a side-profile sketch. The main engine body was created using revolve features, with fan blades modelled and replicated using pattern features.

### Gearbox
Designed a gearbox in Siemens NX and carried out engineering calculations to determine appropriate relative gear sizes before modelling the components.

### Planetary Gearbox
An almost-completed planetary gearbox CAD project developed in Siemens NX. The overall assembly is being refined, with ongoing work focused on improving and finalising the gear teeth geometry.

### Robotic Arm
An ongoing Siemens NX robotic arm design project. The current design is not final and is being iteratively improved, with further development planned to refine the geometry, functionality and overall design.

### Wind Turbine Tower
Designed a wind turbine support tower in Siemens NX and considered structural loading, buckling and column sizing to support the gearbox and rotor while resisting wind forces.

The design was subsequently manufactured as a physical prototype using plywood sticks and adhesive.

### Tower Technical Drawing
Technical drawing associated with the wind turbine tower design.

### Strut & Wheel
Created a strut and wheel assembly in Siemens NX to practise mechanical component modelling and assembly techniques.
